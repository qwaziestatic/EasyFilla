EasyFilla Settings

AI provider

EasyFilla sends your documents to the provider you choose here, using your own key for that provider. Keys are stored separately and only the selected provider's key is ever sent.

Gemini API Key

Used by "Generate AI-Answered Report" to match your uploaded documents to a form's questions. Stored locally in this browser only — never synced to your Google account or sent anywhere except directly to Google's Gemini API when you generate a report.

Flash-Lite models generally allow more requests per minute than Flash; switching also re-paces EasyFilla's request queue automatically. Free-tier limits change over time and differ per project, so we don't print numbers here — check rate limits, pricing, or your live limits in AI Studio.

The connection test lives with the provider selector above, because it tests whichever provider is selected there — not always this one.

Your extracted profile

Facts EasyFilla read from your uploaded documents (email, phone, name, links, etc.), used to answer contact/identity form fields instantly — no AI call. Correct anything mis-read; your edits are kept permanently and are never re-derived. Add facts the parser missed.

Standard declaration defaults

The compliance yes/no questions application portals repeat (disciplinary history, investigations, relatives employed, conflicts of interest, reference consent, willingness to travel, certification). These are never answerable from a CV and never cost an AI call. Set your usual answers once here — they pre-fill every future form for you to review, and are never auto-submitted.

Anthropic API Key

Stored and validated separately from your Gemini key. Used only while Anthropic is the selected provider. Create one at platform.claude.com.

Local data controls

EasyFilla keeps keys and extracted document data only on this device. It automatically removes sensitive data after 30 days without use. You can also remove it immediately below.

Compose defaults

The starting length and tone for every newly composed answer. Each question keeps its own setting after you change it there, so this is a starting point, not an override — changing it here does not rewrite questions you have already tuned. Length is enforced as an explicit word range, not a vague adjective.

Daily request budget

Google doesn't publish a free-tier daily request limit per model, and it changes over time — so EasyFilla shows "daily limit unknown" rather than inventing a number. If you know yours (check AI Studio), set it here and EasyFilla will warn you before starting a run it can't finish. It is also learned automatically the first time you hit a quota error. Requests reset at midnight US Pacific time.

Intro tip

The one-line tip shown over the startup animation ("Great files make great answers.") can be dismissed forever from the splash itself. If you dismissed it and want it back — or you are checking whether it still works — bring it back here. The two permanent notes beside the upload zone and each seed box are never hidden and are unaffected by this.

Diagnostics

EasyFilla always prints a short summary per run (fields found, frames scanned, requests used, what couldn't be filled and why). Turn this on to additionally print one line per field, per frame and per harvested dropdown — useful when reporting a bug, noisy otherwise.

Your API key and the contents of your documents are never written to the console at any setting, so a console copied into a bug report cannot leak them.
